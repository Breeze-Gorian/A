# 失物有踪

《人工智能基础与应用》课程项目：基于文本相似度的校园失物招领匹配系统。

项目用中文文本检索给出最多三条可能的招领记录。页面可展开候选的评分依据，也可查看招领库和逐条实验结果。数据为课堂演示用模拟样本。

## 本地运行

1. 解压源码包，保留文件在同一目录。
2. 用 Edge、Chrome 或 Firefox 打开 index.html。不需要账号、网络、API 密钥或依赖安装。
3. 在“失物匹配”点“藏青色折叠伞”，应将图书馆的 F01 排在首位。点“查看评分依据”查看文本、类别和地点得分。
4. 点“紫色瑜伽垫”体验无匹配提示。在“模型实验”可切换全部案例或仅看不一致，并试跑任意案例。

如果浏览器的本地文件策略拦截资源，可在项目目录运行 python -m http.server 8000，再访问 http://localhost:8000。

## 复现实验

网页“模型实验”会现场计算实验指标。安装 Node.js 的环境也可在项目目录运行：

    node evaluate.cjs
    node evaluate.cjs --json

检索索引在 32 条模拟招领记录上拟合 IDF。12 条标定查询（6 条有对应、6 条无对应）只用于选择展示阈值。24 条留出查询（18 条有对应、6 条无对应）用于最终评估。三组数据可在 data.js 查阅。标定查询与留出查询没有重复文本。作为小规模模拟实验，查询语言与招领语料仍有共同的编写来源，指标不能估计真实校园表现。

| 方法 | Top 1 | Top 3 | MRR@3 |
| --- | ---: | ---: | ---: |
| 二元字符集合 Jaccard | 17/18 | 17/18 | 0.944 |
| TF-IDF 加类别、地点线索，未应用阈值 | 18/18 | 18/18 | 1.000 |
| 实际展示结果，应用阈值 | 13/18 | 13/18 | 0.722 |

有对应查询用于计算排序指标。无对应查询单独计算拒绝表现，正确拒绝 5/6。T07 从基线未进前三改进到内部首位，仍因总分约为 31.2 被阈值拦下。T20 复用了 F01 的类别、颜色与地点，但手柄特征不同，被错误展示为候选。匹配分只是排序分值，失主需要核对细节。

## 制作说明

- 预处理：NFKC 统一字符，转小写，将标点转为空格，按最长优先替换别名，例如“藏青色”归一到“深蓝色”。字符片段不跨空格。
- 索引：从标题、地点和描述中统计二元及三元字符片段。采用对数词频 1 + ln(tf)，平滑逆文档频率为 ln((N + 1)/(df + 1)) + 1。查询中索引未见过的特征按 df = 0 计入向量长度。
- 排序：用 0.80 × 余弦相似度 + 0.12 × 类别命中 + 0.08 × 地点命中，按分值降序排列，平分按记录编号稳定排序。类别和地点命中依据查询中的描述线索，手动筛选独立限制候选范围。
- 展示：在标定集上搜索 0.10 到 0.40 的阈值，步长 0.01。目标为有对应首位正确且展示的比例与无对应正确拒绝的比例的均值，并列取阈值排序后靠中的较小值。当前阈值为 0.33，保留达到阈值的前 3 条。
- 基线：只做字符格式归一化，对原始二元字符集合计算 Jaccard 相似度。使用同一批记录和测试查询，分别列出内部排序与实际展示结果。
- 交互与测试：HTML、CSS、JavaScript 实现三页交互。用 Node.js 验证算法，用 Edge 检查网页匹配、无结果、筛选、错例回放和手机尺寸布局。

| 文件 | 用途 |
| --- | --- |
| index.html、styles.css | 网页结构和布局 |
| data.js | 模拟招领、类别线索、别名、标定集和测试集 |
| engine.js | 预处理、TF-IDF、候选排序、阈值标定和实验计算 |
| app.js | 页面交互、候选解释、筛选和测试回放 |
| evaluate.cjs | 在 Node.js 中复现实验结果 |
| .nojekyll | 供以后在 GitHub Pages 直接发布静态文件 |

项目的匹配计算在浏览器内运行，查询不会上传或保存。网页支持离线打开，也可通过 GitHub Pages 访问部署后的版本。
